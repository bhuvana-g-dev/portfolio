# 💫 Bhuvaneshwari G — Personal Portfolio

> A responsive, data-driven personal portfolio website built with HTML5, CSS3, and Vanilla JavaScript.

[![Live Demo](https://img.shields.io/badge/Live_Demo-portfolio--kappa--sable--18.vercel.app-gold?style=for-the-badge&logo=vercel)](https://portfolio-kappa-sable-18.vercel.app)
[![License: MIT](https://img.shields.io/badge/License-MIT-purple?style=for-the-badge)](LICENSE)

---

## 🌟 Key Features

- **📱 Fully Responsive Design:** Optimized for mobile phones, tablets, and desktop displays.
- **⚡ Vanilla Architecture:** Zero heavy frameworks or runtime dependencies for instant page loads.
- **📊 Data-Driven Rendering:** Dynamic DOM generation from centralized data (`data.js`) with auto-counted stats.
- **🎠 Custom Touch Carousel:** Swipe-friendly, auto-sliding certificate gallery.
- **⌨️ Typewriter Effect:** Dynamic headline typing animation for developer roles.
- **✉️ Asynchronous Contact Form:** AJAX contact submissions integrated with Web3Forms (no page reloads).
- **🎨 Modern Dark Aesthetic:** Custom CSS variables, background grid textures, and smooth scroll animations.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic)
- **Styling:** Modern CSS3 (Custom Properties, Flexbox, Grid, Keyframe Animations)
- **Scripting:** Vanilla JavaScript (ES6+, DOM Manipulation, Intersection Observer API)
- **Deployment:** Vercel

## 📂 Project Structure

```text
portfolio/
├── assets/
│   └── images/
│       ├── certificates/     # Verified course & achievement certificates
│       ├── profile/          # Profile pictures
│       └── projects/         # Project screenshots & previews
├── css/
│   └── style.css             # Unified styling, animations & responsive media queries
├── js/
│   ├── data.js               # Centralized data store (skills, projects, certs)
│   ├── render.js             # Dynamic DOM rendering engine
│   ├── carousel.js           # Certificate slider component
│   └── main.js               # Event listeners, scroll animations & contact form logic
├── index.html                # Main semantic HTML structure
└── README.md                 # Project documentation
```

## 🚀 Running Locally


2. **Open the project:**
   Simply open `index.html` in any modern web browser or use VS Code's **Live Server** extension.
